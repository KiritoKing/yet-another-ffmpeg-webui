## 使用说明

### 自动引导
1. 首次访问用户会看到模式选择提示
2. 未完成引导的用户会自动看到基础引导
3. 引导完成后会记录状态，避免重复显示

### 手动引导
1. 点击工具栏中的帮助按钮
2. 选择"新手引导"查看基础功能介绍
3. 选择"高级功能引导"了解更多高级特性

### 引导步骤
- **欢迎页面**：介绍应用的基本功能
- **命令预设**：介绍可用的视频处理命令
- **执行面板**：介绍参数设置和文件上传
- **任务队列**：介绍任务管理和进度查看
- **设置选项**：介绍运行模式和CDN配置
- **帮助支持**：提供文档和GitHub链接

## 技术特点

1. **非侵入式**：引导不会干扰用户正常操作
2. **可跳过**：用户可以随时关闭引导
3. **状态记忆**：避免重复显示已完成的引导
4. **响应式**：适配不同屏幕尺寸
5. **可扩展**：易于添加新的引导步骤
